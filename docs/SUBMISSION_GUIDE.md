# How to submit this project for the certificate

## 1. Personalise it
Replace `YOUR NAME` and `<your-username>` in these files:
- `README.md` (bottom "About this project" section and the clone link)
- `LICENSE`
- `app/__init__.py` (`__author__`)
- `build_tools/installer.iss` (`AppPublisher`)

## 2. Create the GitHub repository
1. Go to https://github.com/new
2. Repository name: `snova-grid-trader`
3. Public, **without** a README (this project already has one) → **Create repository**
4. In this folder, open a terminal and run:

```bash
git init
git add .
git commit -m "SNova Grid Trader - Advanced Python final project"
git branch -M main
git remote add origin https://github.com/<your-username>/snova-grid-trader.git
git push -u origin main
```

## 3. Fill in the repository "About" box (the gear icon on the right)
The instructor asked that the **About** section says what the project is for:

> **Description:**
> This project is the final project for the Advanced Python Certification course at SLIPD Academy. A MetaTrader 5 Forex grid trading bot desktop app built with Python & Tkinter.

> **Topics:** `python` `tkinter` `metatrader5` `forex` `trading-bot` `grid-trading` `desktop-app` `slipd-academy`

The **README** explains the app itself (already done).

## 4. Post in the class group
Use the format the instructor gave:

```
1. Your Name - https://github.com/<your-username>/snova-grid-trader
```
